第2回の講義資料によると、LoRAとQLoRAの仕組みについて以下の説明があります。
* **LoRAは何を固定し、何を学習するか**
  * 元の重み（本体）は固定して学習せず、細長い2つの小さな行列（低ランクの差分）を学習します（第2回・PDF p.51, p.52）。
* **QLoRAは何を加えるか**
  * LoRAの手法に加え、**元の重みを4bitに圧縮**する点（およびそれによる省メモリ化）を加えます（第2回・PDF p.51, p.52）。

■ベクトル検索 RAG_TOP_K = 20 |3.51 秒 |  入力 9,138 tokens / 出力 209 tokens / モデル応答 2 回| $0.003264 USD| | | |
第2回の講義資料によると、LoRAとQLoRAの仕組みについて以下の通り説明されています。
* **LoRA（Low-Rank Adaptation）**
  * **固定するもの：** 本体の重み（元の重み $W$）を固定し、学習しない（第2回・PDF p.52）。
  * **学習するもの：** 変化分を表す小さな細長い2つの行列（低ランクの行列 $A$ と $B$）の差分だけを学習する（第2回・PDF p.51, p.52）。

* **QLoRA（Quantized LoRA）**
  * LoRAの仕組みに加えて、**元の重みを 4bit（数値を粗く保存）に圧縮**することを行っています（第2回・PDF p.51, p.52）。
